# 文件管理 (TVFile) - Android TV 现代文件管理器

专为智能电视、电视盒子、投影仪及移动智慧屏量身定制的高性能现代化文件管理工具，基于 **Jetpack Compose for TV** 与 **Material 3** 架构打造。

---

## ✨ 核心功能特性

### 1. 📡 Web 局域网 HTTP 免线传输 (端口 45789)
- **极速互传**：应用内置轻量 HTTP 服务器，支持在电视端一键开启/停止服务（默认端口 `45789`）；
- **免客户端**：同一 WiFi 局域网内，手机、电脑、平板只需打开浏览器访问 `http://<电视IP>:45789` 即可直接向电视传输文件；
- **传输目标直达**：所有上传文件自动存入电视内部存储的 `tvfile/` 目录；
- **双向管理与删除**：
  - 手机/电脑网页端支持直接查看电视端已接收的文件列表，支持按安装包、视频、音乐、图片分类筛选；
  - 网页端与电视端双向支持对已接收文件进行单独删除或一键清空；
  - 支持网页端将电视上的接收文件下载回本地电脑/手机。

### 2. 🖥️ 现代大屏 UI 与遥控器交互体验
- **大屏深度适配**：字体、图标针对 3 米客厅视距专项放大（主标题 17.5~18sp 加粗，次标题 14.5~15sp），排版清晰舒适；
- **青蓝极光焦点系统**：所有卡片和按键均配备 `TVCard` / `TVButton`，获焦时呈现 2.5dp 极光青蓝发光描边、背景高亮与 1.05x 平滑微动效，盲操无障碍；
- **左右焦点组隔离 (`focusGroup`)**：彻底切断切目录时焦点跳回左侧 Tab 的震荡问题，零延迟瞬间聚焦新目录首项；
- **防误触双击退出**：在主界面按返回键时弹出 Toast 提示，2 秒内再次按下完全退出应用，防止看文件时误按返回直接退回桌面。

### 3. 📱 自由旋转与横竖屏智能自适应
- **重力感应支持**：配置 `fullSensor`，完美兼容电视盒子（横屏）与添添闺蜜机、当贝 PadGO、KTC 等移动旋转智慧屏；
- **横屏模式**：经典的左侧 Tab 导航栏 + 右侧主工作区双栏布局，文件列表固定为最适宜的 5 列大卡片；
- **竖屏模式**：左侧 Tab 自动平移至屏幕顶部（图标在上、文字在下），内容网格自动调整为紧凑舒展的 3 列排版。

### 4. 🌐 多协议网络存储挂载 (SMB & WebDAV)
- **SMB 2/3 原生支持**：基于 `smbj:0.13.0` 纯 Java 实现，连接群晖/威联通/极空间 NAS 及 Windows/Linux 局域网电脑共享文件夹；
- **根目录自动枚举共享**：引入 `dcerpc` 协议扩展，当共享路径为 `/` 时，自动枚举列出 SMB 主机上的所有共享文件夹；
- **WebDAV 支持**：基于 OkHttp 深度封装，支持 Basic 认证与私有云连接，智能规整多重斜杠路径杜绝 404；
- **服务器配置管理**：支持修改服务器备注名称（重命名）、IP/主机名、端口、认证账号与路径，支持随时删除无用服务器；
- **免输密开机自连**：采用 Room 数据库持久化存储 NAS 服务器配置，退出重开无需重复输入密码。

### 5. 🎬 影视级 ExoPlayer 播放器 (支持 4K 硬解与断点续播)
- **免下载秒播**：集成 `NanoHTTPD` 本地流媒体代理，将远程 SMB / WebDAV 文件流转为带 Range 头的 HTTP 206 流，大视频即点即开、Seek 拖动无卡顿；
- **MediaCodec 4K 硬件加速**：针对主流电视芯片（如 RK3399 等）显式开启硬件 VPU 解码，配置 15s~60s 大缓冲预读，4K 高码率流畅播放；
- **智能断点记忆续播**：后台自动记录播放秒数，再次打开时秒级恢复到上次位置，并浮现“从头播放”提示；
- **倍速播放调节**：支持 `0.75x`、`1.0x`、`1.25x`、`1.5x`、`2.0x`、`3.0x` 多档位自由切换；
- **视频与解码参数浮窗**：遥控器可呼出查看分辨率（4K UHD / 1080P）、编码格式（H.265/HEVC、H.264、VP9、AV1）、实时码率（Mbps）、帧率（FPS）及音频音轨信息；
- **电视专属 OSD 控制台**：单击 OK 暂停/播放，单击左右键跳退/快进 10 秒，长按左右键倍数快进快退，下键呼出控制底栏，4 秒无操作自动淡出。

### 6. 🖼️ 沉浸式相册画廊
- **全屏纯净看图**：去除遮挡界面的浮窗按钮，呈现 100% 纯净大图；
- **遥控器无缝切图**：进入相册后按遥控器 ◀ ▶ 左右键无缝切换上一张/下一张；
- **触屏智能分区**：点击屏幕左侧 30% 翻上一张，右侧 30% 翻下一张，中间 40% 显隐信息栏；
- **页码胶囊指示**：底部半透明胶囊实时显示当前文件名与页码进度（如 `全家福.jpg (3 / 24)`），3.5 秒后自动隐入背景。

### 7. 🔀 自然数文件名排序与偏好持久化
- **自然数混合排序 (Natural Order Sort)**：彻底解决字符字典序导致 `1, 10, 100, 2, 20` 的排序痛点，严格按照人类直觉规整为 `1, 2, 3, 4 ... 10, 20, 100`；
- **多维度排序**：支持“修改时间 (最新优先)”、“修改时间 (最早优先)”、“文件名称 (A - Z)”、“文件名称 (Z - A)”、“文件大小”等 6 种排序模式，文件夹始终智能置顶；
- **偏好持久化**：用户切换的排序规则自动写入本地存储，应用重启后偏好永不丢失。

### 8. 🔌 外接 U 盘自动识别与热插拔
- **动态监听**：广播监听 `ACTION_MEDIA_MOUNTED` / `UNMOUNTED`，即插即显；
- **信息展示**：自动识别 U 盘卷标、文件系统格式（FAT32/exFAT/NTFS）与剩余可用容量进度条；
- **TV 盒子兼容**：底层扫描 Android 盒子特殊挂载路径，保证兼容各类改装机顶盒。

### 9. 📦 APK 系统安装与远程下载安装
- **安全安装**：基于 `FileProvider` 生成安全 `content://` 协议 URI，自动适配 Android 8.0+ 未知来源安装引导；
- **远程 APK 进度弹窗**：点击 SMB / WebDAV 上的安装包时，弹出大屏下载进度弹窗，展示实时百分比进度条与取消按钮，下载完毕自动拉起系统安装器。

### 10. ✂️ 跨存储剪切 / 复制 / 粘贴引擎
- **全存储互通**：支持在内部存储、外接 U 盘、SMB、WebDAV 任意两端进行文件复制与移动；
- **管道流缓冲**：采用 2MB 缓冲块管道流传输，不占用有限的电视运行内存；
- **悬浮进度卡片**：右下角常驻展示传输任务进度百分比、传输速率（MB/s）与已传大小。

## 🛠️ 构建与开发环境

- **Gradle**：9.5.0 (Gradle Wrapper)
- **AGP (Android Gradle Plugin)**：9.3.0
- **Kotlin**：2.1.20
- **Compose Compiler**：2.2.10
- **Compose BOM**：2024.10.01
- **Compose for TV**：`androidx.tv:tv-foundation:1.0.0` / `androidx.tv:tv-material:1.1.0`
- **JDK**：Java 17 (Corretto-24)
- **compileSdk / targetSdk**：37 (minSdk: 23)

### 编译 Release APK 与签名：
```bash
# 1. 编译 Release APK
./gradlew assembleRelease

# 2. 调用本地签名工具完成 V2 + V3 签名
E:\Android\sign\apkSign.bat "<路径_to_apk>"

# 3. 停止守护进程释放内存
./gradlew --stop
```
